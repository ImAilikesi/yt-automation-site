Privacy Policy

Last updated: 29 September 2026 (scopes updated)

Creator Publisher ("the app") is a private tool that one creator uses to upload videos to the creator's own YouTube channels. It has no other users.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • With the youtube.force-ssl permission: it uploads videos, captions and thumbnails; sets their title, description, tags and publish time; manages playlists and the channel description and banner; and reads the ID and name of the authorised channel, to confirm that videos go to the correct channel.
  • With the yt-analytics.readonly permission: it reads view and retention statistics of the creator's own videos, to decide which topics to make next.

Storage and sharing

The OAuth refresh token and the channel ID and name are stored only on the creator's own computer, in a file readable only by that user. The app has no server, does not collect data about viewers or other people, does not sell or share any data, and does not use data for advertising.

Deleting data and revoking access

Access can be revoked at any time at Google security settings. Deleting the local token file removes all stored data. Stored data is deleted within 7 days after access is revoked.
